<h2>♬ Sobre o Projeto</h2>

<p>O <strong>Sistema Musical</strong> é uma plataforma desenvolvida com a proposta de permitir que cada usuário construa e organize sua própria biblioteca musical, reunindo seus artistas e músicas favoritos em um único ambiente.</p>

<p>A ideia é oferecer uma experiência simples e organizada para catalogar músicas, registrar informações sobre artistas, identificar álbuns e gêneros musicais e acessar conteúdos relacionados, como vídeos do YouTube e letras de músicas.</p>

<p>Diferentemente de uma plataforma de streaming tradicional, o foco do projeto está no <strong>gerenciamento de uma coleção musical personalizada</strong>. O usuário é responsável por montar seu próprio acervo, adicionando e organizando as informações de acordo com suas preferências.</p>

<p>Este repositório apresenta a etapa de <strong>Front-end</strong> do Trabalho de Conclusão do Semestre, desenvolvida utilizando HTML5 e CSS3.</p>

<h2>🎼 Como o Sistema Funciona?</h2>

<p>A navegação foi pensada para acompanhar a organização natural de uma biblioteca musical:</p>

<p><strong>01 — Acesso ao Sistema</strong></p>
<p>O usuário encontra uma tela de login com campos para identificação e senha.</p>

<p><strong>02 — Menu Principal</strong></p>
<p>Após a entrada, o menu apresenta três caminhos principais: gerenciamento de artistas, cadastro de músicas e acesso à biblioteca.</p>

<p><strong>03 — Cadastro de Artistas</strong></p>
<p>Antes de organizar as músicas, é possível registrar os artistas que farão parte da coleção, incluindo informações de identificação e origem.</p>

<p><strong>04 — Cadastro de Músicas</strong></p>
<p>Cada música pode ser associada a um artista e receber informações complementares, como álbum, gênero, capa, letra e endereço do vídeo no YouTube.</p>

<p><strong>05 — Biblioteca Musical</strong></p>
<p>O acervo é apresentado em formato de tabela, permitindo visualizar as informações das músicas e utilizar campos de pesquisa e filtros para localizar registros.</p>

<h2>✧ Tecnologias e Desenvolvimento</h2>

<p>O Front-end foi construído utilizando tecnologias fundamentais do desenvolvimento web:</p>

<ul>
  <li><strong>HTML5:</strong> responsável pela estruturação das páginas, organização dos conteúdos, formulários, campos de entrada, tabelas e elementos de navegação.</li>
  <li><strong>CSS3:</strong> utilizado na construção da identidade visual, estilização dos componentes, organização dos layouts, cores, espaçamentos, botões e cartões.</li>
</ul>

<p>A interface segue uma identidade visual baseada em tons de azul, branco e cinza, com elementos relacionados ao universo musical. A organização visual busca facilitar a navegação e manter uma apresentação consistente entre as diferentes telas.</p>

<h2>▸ Escopo desta Etapa</h2>

<p>Esta entrega contempla exclusivamente o desenvolvimento do <strong>Front-end</strong>, responsável pela estrutura e apresentação visual da plataforma.</p>
